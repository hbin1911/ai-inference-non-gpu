# AI Model Inference in Non-GPU Environment

## Project Overview
This project demonstrates AI model inference using Hugging Face transformer models in Google Colab. The focus is on understanding how inference works in CPU and GPU environments.

## Features
- DistilBERT text classification
- CPU vs GPU timing comparison
- Hugging Face pipeline usage
- AI inference execution

## Technologies Used
- Python
- Google Colab
- Hugging Face Transformers
- scikit-learn

## Models Used
- DistilBERT
- TinyLlama
- Phi-3 Mini

## Objective
To study and implement AI inference in non-GPU environments and compare performance between CPU and GPU execution.
